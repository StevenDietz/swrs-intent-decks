How to use it

  1. Click Copy for Outlook.
  2. In Outlook, put the cursor where you want it and press Ctrl + V.
  3. The image lands as a clickable link — clicking it opens the deck.

If the button is blocked by your browser, use Select it instead, then Ctrl + C, then paste. Paste with Ctrl + V, not Paste Special → Picture — Picture strips the hyperlink. Recipients whose mail client blocks images see the alt text and the two text links underneath, so the message still lands.
